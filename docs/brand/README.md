# Identidade Visual

Diretrizes iniciais da identidade visual oficial do ORDIA.

## 1. Marca

**ORDIA** é a marca oficial do projeto.

O projeto anteriormente utilizou outros nomes durante a fase de concepção. A identidade atual e oficial é ORDIA.

## 2. Símbolo oficial

O símbolo definitivo adotado é o **Conceito Fusão**.

O conceito combina três ideias visuais:

1. **O como sistema:** um anel modular representa o sistema como um conjunto organizado.
2. **Órbita integrada:** elementos orbitais representam módulos e componentes funcionando em conjunto.
3. **Eixo central:** um eixo conecta os elementos e representa fluxo, coordenação e continuidade.

O conjunto representa a ideia central do ORDIA: diferentes partes operando de forma integrada em um único sistema.

## 3. Princípios da marca

A identidade deve transmitir:

- integração;
- tecnologia;
- organização;
- confiabilidade;
- clareza;
- evolução;
- gestão centralizada.

A marca deve evitar a dependência de símbolos hospitalares genéricos como cruzes, estetoscópios ou representações literais de hospitais.

## 4. Uso do símbolo

O símbolo deve funcionar de forma independente do wordmark **ORDIA**.

Aplicações previstas:

- favicon;
- ícone do aplicativo;
- tela de login;
- menu lateral;
- carregamento/splash screen;
- documentação;
- apresentações;
- materiais institucionais.

## 5. Wordmark

O wordmark deve utilizar tipografia geométrica, limpa e contemporânea, mantendo boa leitura em interfaces digitais.

A composição deve preservar espaço suficiente entre símbolo e palavra e não deve deformar o símbolo para acomodar tamanhos menores.

## 6. Cores

A direção visual atual utiliza uma combinação de azul profundo, azul tecnológico e tons de teal/turquesa.

Os valores exatos de cor deverão ser consolidados posteriormente em tokens oficiais de design para garantir consistência entre frontend, documentação e materiais externos.

## 7. Versões

A identidade deverá possuir, no mínimo:

- versão principal para fundo claro;
- versão principal para fundo escuro;
- versão monocromática clara;
- versão monocromática escura;
- símbolo isolado;
- wordmark + símbolo.

## 8. Regra de consistência

O símbolo não deve ser redesenhado ou reinterpretado casualmente entre módulos do sistema.

Alterações estruturais da identidade visual devem ser registradas como decisão de produto/design para manter uma linguagem única em toda a plataforma.

## 9. Relação com o produto

A identidade visual não é apenas decorativa. O conceito do símbolo reflete a arquitetura e a proposta do ORDIA:

```text
                    MÓDULOS
                 ↗    ↑    ↖
              ───     ●     ───
                 ↘    ↓    ↙
                    NÚCLEO
```

O núcleo representa a plataforma; os elementos conectados representam os diferentes domínios e fluxos que compõem o sistema.

## Status

**Definitivo para a identidade atual do projeto.**

O conceito Fusão é a referência oficial enquanto a identidade visual detalhada não receber uma nova decisão formal.
