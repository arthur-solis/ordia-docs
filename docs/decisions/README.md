# Decisões Arquiteturais

Registro das decisões técnicas importantes do ORDIA usando **ADRs (Architecture Decision Records)**.

## Formato recomendado

Cada ADR deve registrar:

1. Contexto
2. Problema
3. Decisão
4. Alternativas consideradas
5. Consequências
6. Status
7. Data

## Convenção de nomes

```text
ADR-0001-nome-da-decisao.md
ADR-0002-outra-decisao.md
```

As decisões devem ser numeradas e não devem ser apagadas quando forem substituídas. Uma decisão antiga deve ser marcada como **Superseded** quando uma nova decisão assumir seu lugar.
