# Documento Mestre

Documento central do ORDIA.

## Objetivo

Registrar a visão geral do produto, seu propósito, escopo, requisitos, módulos e regras de negócio em um único ponto de referência.

## Seções planejadas

- Visão do produto
- Problema e objetivos
- Público-alvo
- Escopo
- Requisitos funcionais
- Requisitos não funcionais
- Módulos
- Regras de negócio
- Fluxos principais
- Glossário
- Roadmap
